Remove a clamped round-shank bit from an unpowered handheld keyless drill and leave it in the parts tray.

Run inside the installed Isaac Lab-Arena YAM environment, from this task folder:

    inspect-robots run --embodiment yam_arena --policy yam_scripted -E task=$PWD/task.py -E object_jitter=0 -E control_hz=20 --instruction "Remove the drill bit from the unpowered drill and leave the bit in the tray." --scorer task_score --max-steps 1600 --store-frames --log-dir logs/demo

The left hand holds the existing pistol grip. The right hand follows a fixed correction recorded during development, with no simulator-pose feedback, and turns the hollow chuck sleeve. It withdraws; the left hand tips the open chuck 45 degrees over the tray, returns level, sets the drill down and releases it. The demo reads no object state. Joint state is used only by scoring and optional diagnostic logging (CHUCK_DEBUG=1). No attachments, object pose writes, injected torques or contact-triggered success latches are used.
