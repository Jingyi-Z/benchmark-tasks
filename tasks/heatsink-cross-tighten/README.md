# Tighten Four Spring Thumb Nuts on a 1U Server CPU Cold Plate to Seat It Flat

Builds on the idea of TK-2HL6E9 / PR #456, TK-25G7NE / PR #330, TK-WSHWFM / PR #132, and TK-P5JGDU / PR #2059, which were not accepted because unthreaded spring buttons and software warp flags omitted threaded plate seating, the instruction gave away the tightening sequence, or whole-run tilt vetoes penalized recoverable handling; this version models a 6-DOF 1:1 Alphacool `Eisblock XPX Pro 1U` server CPU liquid cold plate (`P/N 12936`, `79.0 x 63.8 x 25.5 mm`, `0.265 kg` with bracket and dry fittings) on Intel `LGA2011 Square ILM` (`80.0 x 80.0 mm`) `M4 x 0.70 mm` studs with four helically coupled `PhysxMimicJointAPI` spring thumb nuts over a central `38.0 x 38.0 mm` processor fulcrum, using a goal-only instruction and pure final-state contact and flatness scoring.

## Overview

This task evaluates bimanual progressive cross-pattern fastener seating on AI server hardware: turning four corner `18.0 mm` ribbed `M4 x 0.70 mm` thumb nuts on an `80.0 x 80.0 mm` `LGA2011 Square ILM` grid (`3.43` turns = `2.40 mm` seated travel) to compress a loose 6-DOF `1U` direct-to-chip liquid cold plate against four pocketed `M4` return springs onto an instrumented `38.0 x 38.0 mm` CPU integrated heat spreader (IHS) datum. Tightening one corner or one side alone physically pivots the cold plate across the central IHS fulcrum (`> 1.4 mm` four-corner tilt spread across the `80.0 x 80.0 mm` stud square), whereas alternating diagonal cross passes keep the bracket level (`<= 0.45 mm` spread) and bring the copper base into flush four-corner contact.

## Run

```bash
inspect-robots run --embodiment yam_arena --policy yam_scripted -E task=task.py -E object_jitter=0 -E control_hz=20 --instruction "<see task.json>" --scorer task_score --max-steps 2800 --store-frames --log-dir logs
inspect-robots run --embodiment yam_arena --policy dream -E task=task.py -E object_jitter=0 -E control_hz=20 --instruction "<see task.json>" --scorer task_score --max-steps 2800 --store-frames --log-dir logs
```

One trial takes about 5 to 6 minutes on one GPU; the layout is fixed (`object_jitter=0`, no seeds). `HEATSINK_MODE=uneven_one_side` (`expected 0.0`), `HEATSINK_MODE=uneven_one_corner` (`expected 0.0`), and `HEATSINK_MODE=half_even_pass` (`expected 0.5`) run the physical controls with `yam_scripted`. `python check_path.py` runs the offline 578-hull trajectory, 3D geometry, spring-pocket travel, an endpoint reconstruction from the saved native logs (not a full-history replay), and 23-case scorer checks.

## Real-Trial Bill of Materials, Pocketed Return-Spring Stack, Instrumented IHS Datum, and Reset

1. **Cold plate & Square-ILM board/bolster options (dry, unpowered, zero consumables):**
   - **Cold plate kit:** Alphacool `Eisblock XPX Pro 1U` (`Alphacool P/N 12936`, `~USD 85`; `79.0 x 63.8 x 25.5 mm` nylon housing + nickel/copper base, `205 g` bare + `60 g` `96.0 x 96.0 mm` steel `LGA2011` bracket and `2x` dry `Eiszapfen G1/4` barbs with short `10/13 mm` PVC hose stubs, `~USD 12` = `0.265 kg` total).
   - **Option A (`ASUS X99-A` Square-ILM motherboard) or Option B (`square_ilm_bolster_plate.stl`):** Mount either a used unpowered `ASUS X99-A` (`LGA2011-v3` `80.0 x 80.0 mm` **Square ILM** ATX board, `~USD 65`, CMOS cell removed; avoid Narrow-ILM boards) + used `Xeon E5-2600 v3/v4` CPU (`38.0 x 38.0 mm` IHS, `~USD 10`) fitted on `4x M4 x 0.7 x 45 mm` stainless threaded studs (`McMaster 93805A229`, `~USD 8`) with `4x` printed/machined `square_ilm_spring_standoff_cup.stl` (`10.50 x 10.50 x 24.30 mm`, shimmed so the cup mouth rim stands `+24.30 mm` forward of the instrumented IHS datum), **or** print `square_ilm_bolster_plate.stl` (`python generate_fixture_stl.py`, `< USD 6` PETG/PLA) on `2020` extrusion uprights (`~USD 20`) with instrumented IHS datum at `x = 0.4020 m, y = 0.000 m, z = 0.9125 m`.
2. **Buildable pocketed return-spring assembly (`matching sp_0..3 = 220 N/m per corner, 880 N/m combined`):**
   - **Spring SKU:** `4x` **`Lee Spring LC 016C 12 S`** (`Type 302 Stainless Steel, Passivated, Squared & Ground Ends`, `~USD 2.50` each / `~USD 10` for 4): `OD = 0.240 in = 6.10 mm`, `wire = 0.016 in = 0.41 mm`, **`ID = 0.208 in = 5.28 mm`** (`1.28 mm` diametral clearance over the `4.00 mm` `M4x0.7` stud), `free length L_free = 0.938 in = 23.83 mm`, `solid height L_solid = 0.129 in = 3.29 mm`, catalog rate `1.24 lbf/in = 0.217 N/mm = 217 N/m` per corner (`4 x 217 = 868 N/m` combined across four corners, within `1.4%` of `task.py`'s `4 x 220 = 880 N/m`).
   - **Spring pocket & follower seat cross-section (`per corner along world X`):**
     - Each `10.50 x 10.50 mm` standoff (`mouth rim at x = 0.3777 m`, `+24.30 mm` forward of the `x = 0.4020 m` instrumented IHS datum) has a coaxial **`7.00 x 7.00 mm` counterbore pocket `18.40 mm` deep** (`pocket floor at x = 0.3961 m`, `0.90 mm` clearance around the `6.10 mm` spring OD) above a solid `4.20 mm`-bored M4 base.
     - Slip `1x LC 016C 12 S` spring + `1x` `spring_follower_collar.stl` (`6.50 x 6.50 x 2.00 mm`, `4.30 mm` M4 bore) into each pocket over the `M4x0.7` stud, then install the cold-plate bracket, top springs, and four `M4x0.7` thumb nuts (`witness-marked at 0.00 turns`).
     - **At reset (`cold plate 2.40 mm proud, bracket rear at x = 0.3753 m`):** Pocket floor (`0.3961 m`) to bracket rear (`0.3753 m`) is `20.80 mm`; subtracting the `2.00 mm` follower collar (`its rear 0.40 mm and its front, against the bracket ear, 2.40 mm out of the x = 0.3777 m pocket mouth`) gives **`L_reset = 18.80 mm` installed coil length** (`5.03 mm` compression -> `1.09 N` per corner = `4.36 N` total preload holding the `265 g` bracket against the backed-off nut collars).
     - **Simulation vs real springs:** the simulator's spring drives match the rate but not the preload: about `0 N` at reset and `2.1 N` total seated in simulation, versus about `4.4 N` and `6.4 N` total for the real springs. At these low forces this does not change the turning or the progressive seating that the task tests.
     - **At full seating (`cold plate contacting instrumented IHS datum at x = 0.4020 m, bracket rear at x = 0.3777 m`):** Pocket floor (`0.3961 m`) to bracket rear (`0.3777 m`) is `18.40 mm`; subtracting the `2.00 mm` follower collar (retracted flush at `x = 0.3777 m` inside the pocket) gives **`L_seated = 16.40 mm` installed coil length** — **`13.11 mm` above the `3.29 mm` solid height** (`zero coil bind`, `6.45 N` total seated force).
3. **Instrumented `0.135 mm` IHS contact datum, open-circuit control, and real-trial scoring:**
   - Bond a `38.0 x 38.0 x 0.100 mm` polyimide (`Kapton`) insulating sheet over the CPU IHS (`bare IHS pad on square_ilm_bolster_plate.stl is 2.865 mm tall so adding 0.100 mm Kapton + four isolated 6 x 6 x 0.035 mm corner copper-foil pads places the instrumented IHS pad surface at exact z_stl = 8.000 mm = world x = 0.4020 m`). Wire each corner pad through its own `1 kOhm` resistor + LED to `+3.3 V` with the return clip on the copper cold-plate base.
   - **Open-circuit reset check:** Before every trial (`with studs, springs, bracket, and nuts fully installed at the 2.40 mm reset stop`), verify all `4` LEDs are **OFF**, confirming zero electrical bypass through the grounded bolster, studs, or bracket.
   - **Final-state scoring (`after 1.0 s video stillness and >= 80 mm tape-measure hand clearance`):**
     - **`0.5`:** `>= 2` thumb nuts advanced `>= 1.3` turns (`>= 0.90 mm` shoulder caliper advance), center gap `<= 1.65 mm`, and `80.0 x 80.0 mm` four-stud-ear caliper spread `<= 0.90 mm`.
     - **`1.0`:** All `4` thumb nuts advanced `>= 3.15` turns (`>= 2.20 mm`), **all `4` corner instrumented-IHS LEDs lit**, a `0.10 mm` non-conductive feeler strip blocked between the copper base and all four outer edges of the `38 x 38 mm` instrumented IHS pad, and `80.0 x 80.0 mm` stud-ear caliper spread `<= 0.45 mm` (`modeled in sim by collars >= 2.20 mm, ihs_gap_mm in [-0.20, +0.24] mm, and corner_spread_mm <= 0.45 mm`).
